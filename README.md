# Parameterized-ALU
----
Designing a configurable-width Arithmetic Logic Unit (ALU) implemented in Verilog with configurable data width and support for arithmetic, logical, comparison, and bitwise operations.

In Progress 🚧 
---
This project is being developed as a modular RTL design using Verilog and will be progressively verified through simulation and implemented on an FPGA using AMD Vivado.
- First Design -- Combinational ALU
